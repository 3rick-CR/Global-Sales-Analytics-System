# Data Source: Global Superstore

Esta carpeta contiene el conjunto de datos transaccionales utilizado para el proyecto.

## Fuente Original:
* **Dataset:** [Global Superstore en Kaggle](https://www.kaggle.com/datasets/anandaramg/global-superstore?resource=download)
* **Descripción:** Conjunto de datos con registros de ventas, beneficios, mercados y categorías de productos a nivel global.

## Contenido:
* **Global_Superstore.csv:** Archivo original con 51,290 registros

## Notas:
* Los datos incluyen información desde 2011 hasta el 2014
* Se requiere limpieza de columnas con caracteres especiales y normalización de formatos de fecha antes del análisis.
* El dataset se utiliza con fines educativos para demostrar habilidades de ETL y análisis de negocio.
